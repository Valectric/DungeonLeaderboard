# Tileset pass — what three reviews established

Staged, **not imported**: `C:/Users/JohanHoltby/Documents/dungeon-keyart/tileset-final.png`
Generated by `codex exec` against the moodboard crops, then reviewed three times by an agent that
never saw the generation brief — so it could not be primed by the same framing that produced the art.

## The numbers that matter, measured off `style-tiles.png`

| metric | target | v1 | v2 | v3 | final |
|---|---|---|---|---|---|
| sheet mean luminance | 33 | 24 | 55 | 17.5 | **33.0** |
| **wall / floor luminance** | **0.98** | — | — | 0.71 | **1.05** |
| lit rim / wall | 1.93 | — | — | 1.96 | 1.96 |
| pixels above L100 | ~1.1% | 0.6% | 22.6% | 0.6% | 1.5% |
| stone HSV saturation | 15–23% | 40% | 4% | — | 44% |

**The single most useful finding:** the moodboard does **not** separate wall from floor by value —
they sit at the same mean. It separates them with the **rim highlight**, which is ~90% brighter than
the floor. Both early attempts drew a bright lit slab for the wall instead, which is a redraw rather
than a grade.

**The second:** mean luminance was never the failing metric. Tuning it is what produced the
oscillation — 24, then 55, then 17.5. Tune **wall/floor** and **face/mortar** instead; both are
checkable in either direction.

## What is right about the staged sheet

Complete autotile set (corners, T, ends, columns). Six genuinely distinct floor variants — plain,
cracked, rubble, puddle, moss, blood — verified seam-neutral, border within 3% of centre with no
directional lighting. Torch sconces where the flame integrates into the block. The arch finally uses
the same *material* as the wall run: L 53.1 / sat 40.9% / B−G +18.5 against the wall's 53.0 / 43.6% /
+18.3, indistinguishable.

## What still blocks import

1. **The archway is not on the grid**, for the fourth iteration running. ~1.5 tiles wide, opening
   centred a fifth of a tile off, crossing a cell boundary. It cannot be placed in a 32px tilemap.
   Give the next attempt a *number*: its island must be the same width as every other tile.
2. **The sheet is not a uniform atlas.** Islands measure 148–152px wide by 131–177px tall, so it
   cannot be auto-sliced at any pitch — every tile needs hand-cropping.
3. **The floor repeats visibly.** Tiled-field autocorrelation at one tile lag is 0.75 against the
   moodboard's 0.24. Vary the brick layout between variants; do **not** raise contrast to compensate.
4. **Optional, the author's call:** the stone is ~2.3× more violet than the rendered reference tiles.
   It matches `style-palette.png` almost exactly, so it is defensible — the two style authorities
   disagree, the swatches being roughly twice as chromatic as the rooms. A one-line saturation
   correction pulls it ~30% toward `style-tiles.png` if wanted.

## Process notes worth keeping

- **`--reference` reaching the agent is not the same as reaching the image model.** Both runs were
  told explicitly to pass references through `referenced_image_paths`, and confirmed doing so.
- **The unbiased reviewer beat my own eye every time.** I looked at v1's archway and called it a
  match; it measured four times darker than the wall. I did not see the floor vignette that would
  have drawn a black grid across every room. And my gamma correction hit the one number I was
  watching while moving three I was not.
- Codex cannot save into a read-only workspace. It still generates; read the path it prints and copy
  the file out.
